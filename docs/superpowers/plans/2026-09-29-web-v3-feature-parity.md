## 第一批：每日练习完整流程

1. 复用 `data/recommendation/default-catalog.json`，只发布已跟踪的公开推荐元数据，不读取私人题库文件。
2. 推荐搜索、难度筛选、目录导入导出；从推荐加入个人题库后能直接进入练习。
3. 读取现有个人版排序语义，提供每天 1–5 题、目标标签、难度压力、冷却周期；规则排序即可工作，不依赖 AI。
4. 今日条目操作与个人反馈持久化，已有个人题库仍可参与计划。
5. 对公开 LeetCode 获取限制目标域名、slug、超时、响应大小；使用纯文本题面，保留来源。原始函数参数样例不冒充 ACM 输入协议。
6. 五视图工作台沿用已上线的账号绑定草稿、冲突处理、完整备份和隔离 Python，不重做账户系统。
7. 优先复用 `user_settings` / `daily_plans`，如需迁移新建文件，不修改生产已执行的 0001/0002。

验收：线上登录 → 搜索推荐 → 获取题面/预览 → 保存个人题 → 输入 ACM 样例 → Python 自测 → 修改今日偏好 → 生成计划 → 标记反馈 → 刷新读取。另验证访客入口、旧备份格式兼容与窄屏导航。

## Java/C++ 的完成条件

它们不是 Workers Functions 中可以直接启动的系统编译器。需要先确认独立执行资源，包含执行任务与应用数据/凭据隔离、禁网、限时限内存、并发限制、取消与清理。只有真实运行通过后才标为追齐；不能只添加语言选择框，或让浏览器调用未隔离的旧个人 API 来宣称完成。
