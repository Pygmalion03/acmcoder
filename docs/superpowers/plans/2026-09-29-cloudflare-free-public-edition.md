## 目标与交付边界

建立一个不依赖浏览器插件、支持多用户、Cloudflare 新增服务账单为 0 的网站。保留 NAS 上已经部署的 v3.0.4 个人版，以及原 `api.pygmalion.top` 入口。先证明完整的免费路径，再分阶段扩展；阶段完成不代表整个计划完成。

免费约束：只使用 Pages、Workers Free、D1 Free；不得开通 Workers Paid、Containers/Sandbox 付费方案、R2 按量订阅、付费模型或信用卡试用。若账户已有付费套餐，不能把其含量当成免费套餐，部署前确认计费归属。超过额度时限流/暂停，不能自动付费。已有域名续费、NAS 电费不算新增云服务费。默认平台域名可用于预发布。

### 已接受的产品需求

- 网站提供题库、编辑器、今日计划、进度和重练；核心流程不依赖 AI。
- Python 在用户浏览器内执行，支持 stdin/stdout/stderr、停止、超时、输出上限；NAS 不可用时仍可练习。
- 登录用户的题库、草稿、提交和设置完全隔离；匿名用户可先体验浏览器 Python，草稿留在本机。
- D1 保存账户、个人题库、草稿、进度和有限提交历史，支持跨设备恢复及冲突处理。
- 添加题目支持链接收藏、允许获取的题面导入、手动题面和 JSON 导入；提供预览、去重和失败备用入口。公共题库仅用原创或明确许可内容，不把现有 LeetCode 题面自动公开。
- 原始样例与 ACM stdin/expected 分开保存，常见数组、字符串、矩阵转换必须可预览修改；复杂链表/树不假装自动处理。
- 支持搜索、筛选、收藏、删除、导入、导出；保留来源链接。
- Java/C++ 远程执行初期仅受邀用户可用，必须与 NAS 应用/数据/家庭网络隔离并限制并发与资源；该安全条件不满足时入口显示暂不可用，不能接到现有个人版内置 runner。
- 自测显示“自测通过”，不宣称通过 LeetCode 隐藏测试，不建立依赖浏览器结果的可信排行榜。
- 插件后续定位为可选采集助手；本次不以插件商店发布或插件改版作为上线前提。
- 公共付费 AI 默认关闭；不读取、迁移或向公众暴露个人版模型设置。
- 数据可导出、删除；限制历史/日志容量，具备备份、恢复和额度提示。

## 架构与文件职责

优先新增独立 `cloudflare/` 部署入口并复用现有纯前端/状态逻辑，避免破坏 NAS 运行方式，也不要无必要改用大型框架。可调整目录名，但须在记录中说明。

- `cloudflare/public/`：免费版界面、浏览器运行适配、静态资源。
- `cloudflare/functions/` 或 Worker 入口：同源业务 API、认证、权限、额度处理；使用 Pages Functions 或 Workers 中最轻的真实可部署路线。
- `cloudflare/migrations/`：D1 版本化 schema 和索引。
- `cloudflare/runner/`：隔离浏览器 Python 执行环境；独立来源或等效沙箱边界。
- `cloudflare/wrangler.*`、构建脚本：可复现免费部署，资源 ID 仅填真实观测值，不能伪造。
- `tests/`：用户隔离、同步冲突、导入、配额、运行边界的相关回归。
- 部署文档：免费资源、限制、迁移、回滚、备份及实际已验证状态；基础设施事实由父 agent 更新相邻 003 仓库，保留该仓库既有改动。

Python 使用固定版本 Pyodide（以官方稳定发行和实际加载为准）。不能让任意用户 Python 在携带网站权限的同源环境中自由访问账户 API；使用独立无凭据来源/隔离 iframe + Web Worker，严格验证消息来源和任务 ID，限制网络能力。登录凭据和私人数据不传入运行上下文。Web Worker 负责 UI 不阻塞，不把它本身当作权限隔离。
