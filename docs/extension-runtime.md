# 插件与网站的离线运行

完整插件包和网站资源均包含 Python、C++17、Java 8。插件安装后无需网站、本地服务或账号即可练习；网站需先在设置中完成离线资源准备。原版侧栏通过本地服务运行代码，与当前独立运行器是两条路径。

## 构建与安装

从 Release 下载完整插件 ZIP，或在 Node.js 22+、Python 3 的环境中构建：

```sh
npm ci --ignore-scripts
node scripts/build-clients.mjs extension
```

首次构建需联网下载固定版本资源，脚本验证摘要。安装目录是 `dist/extension/`，包含共享界面、编辑器、语言资源和许可证；源码 `extension/` 不能直接替代它。Chrome / Edge 扩展管理页开启开发者模式，加载含 `manifest.json` 的生成目录。日常使用不需要测试浏览器，商店目前未上架。

升级更新原安装目录后重新加载，保留扩展身份。卸载或换目录前先导出备份；手动安装流程见[插件使用](edge-extension.md)。

## 语言与隔离

| 语言 | 浏览器运行实现 | 主要边界 |
| --- | --- | --- |
| Python | Pyodide 0.29.3 | 随包资源；每次任务使用隔离 Worker |
| C++ | 固定 LLVM / WASI 工具链 | C++17；浏览器虚拟文件与内存有限制 |
| Java | Doppio / Java 8 运行资源 | Java 8；编译期间保持页面可见 |

主页面只向隔离环境交付运行资源、代码、stdin 和任务标识，不交付账号凭据或期望输出。沙箱限制网络和主页面访问，消息校验来源、nonce 与当前任务 ID。取消或运行超时会结束当前任务，旧回包不能写入后续结果。执行时间和输出均有上限；浏览器资源初始化时间与程序执行时间分别处理。

浏览器运行器适合个人 ACM 输入输出练习，不能等同于本机完整语言环境。需要原生库或不同 JDK 时使用[本地 / Docker](deployment.md)。第三方许可和对应源码分发要求见[第三方声明](../THIRD_PARTY_NOTICES.md)，不要只取运行二进制而删掉许可证。

## 断网验证

1. 先保存一道题及可运行的 ACM 样例。网站还需等待设置中的「网站离线」资源就绪。
2. 断网后重开工作区，检查原草稿、输入、重写历史，并运行已保存样例。
3. 停止一个无限循环，确认能继续输入和再次运行；恢复联网后再观察同步状态。

插件运行资源随包保留。网站资源受浏览器缓存策略影响，清除网站数据或缓存被回收后需重新准备。抓取外部题目、云端同步和在线模型请求不属于离线能力。

## 接续与账号

同浏览器「在网站继续 / 在插件继续」只在用户点击后传递选中题目，目标端预览确认后导入；不要求账号，也不把正文写进 URL。接续标识短期有效、一次消费并绑定目标页面。跨浏览器或无法接续时使用完整备份。

账号同步通过设备授权连接。未登记 ID 的手动安装使用网站设备确认，不要求用户修改 OAuth 回调白名单。网站关闭后，已授权插件仍能同步；撤销设备会停止同步但保留本机练习。自托管需修改公开部署配置并重新构建完整插件，使 origin 和 manifest 权限配套；详见[Cloudflare 部署](../cloudflare/README.md)。

历史实际验证见 [v4.1.0 发行说明](releases/v4.1.0.md)和[需求验收](releases/unified-requirement-audit.md)。这些回执保留当时版本和环境，不代表当前开发构建已通过商店审核或所有公网验收。
