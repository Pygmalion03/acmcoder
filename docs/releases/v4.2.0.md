# ACMCoder v4.2.0

本版完善个人长期练习工作区：代码编辑器、可调分栏、多样例批量运行、可检索运行快照、重写差异，以及当天固定的练习队列。网站、插件和本地 / Docker 共用这些功能。

新 AI 问答按轮保存并分页读取，旧对话保持可读、可备份；回答保存失败后可重试保存，当前会话不会重复请求模型。本地查询避免整库只读复制。云端 `0007_record_capacity_repair.sql` 修正级联删除的容量核算，保留正文、修订、同步游标与删除标记。

部署地址集中配置，插件权限、认证和接续地址随构建生成；凭据绑定来源。旧入口保留导出和环境设置，并引导统一工作区。Docker 源码安装使用独立前端构建阶段，支持非 root 读取应用文件。

发布前全量 514 项测试通过；隔离 Docker 三语言执行及重建持久化、超过 2 MiB 学习记录的真实 HTTP / 重启 / 新目录恢复、隔离 D1 迁移、真实浏览器工作台均已验证。最终源码提交、生产部署、镜像摘要和发布后的升级验收以本版 `release-manifest.json` 关联结果为准。Linux arm64 不扩大为已实际执行验收。

升级前导出完整学习备份；插件更新到原安装目录并重新加载。本地服务更新代码和静态资源后重启；生产数据库先保留恢复点，再执行尚未应用的 `0007`，并配套部署新 API。旧客户端可能无法展示新对话轮记录，回退时使用独立备份与升级前副本。详见 [升级与回退](../upgrade.md)。

网站基本练习及完整插件均支持 Python、C++17、Java 8；本地 / Docker 使用所安装的语言工具链。账号同步可选，离线不调用外部 AI。Chrome 商店上架继续暂缓。
