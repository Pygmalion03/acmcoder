# ACMCoder v3.0.4

This release adds conversational AI assistance and immediate reinforcement practice to the Web workspace. Conversations and drafts survive refreshes and can be restored by problem and language. The Docker app retains its bundled seed problems while persisting memory and recommendation data in separate writable directories.

Reliability fixes cover problem switching during slow or failed loads, run results after edits or rapid repeat runs, stale AI replies after reinforcement, interrupted or invalid API responses, and explicit trusted hosts for deployed domains. The image publishing smoke test now checks bundled seed problems and runs Java, C++, and Python inside the hardened app container.

Images: `ghcr.io/pygmalion03/acmcoder-app:v3.0.4` and `ghcr.io/pygmalion03/acmcoder-runner:v3.0.4` (linux/amd64 and linux/arm64).

For Docker installation, use `docker-compose.prebuilt.yml`. When accessing the service through a domain, set `ACMCODER_TRUSTED_HOSTS` to its exact hostname and preserve that Host in the reverse proxy. Existing `data/memory` and `data/recommendation` directories remain mounted separately.
