# ACMCoder v4.0.0-rc.4

浏览器 C++17 候选实现，仍在验收中；公开网站暂为 rc.3，rc.4 尚未完成公网
静态分发与真实离线插件实装，不代表稳定发行或商店已经上架。

- 统一网站/插件练习页增加独立 C++ 草稿和隔离 WASM Clang 运行器；本地
  Python/C++/Java 保持原生工具链。
- C++17、UTF-8 stdin 和逐流输出；编译30秒/执行5秒，上限分别适用于
  编译器、文件系统和用户 WASM。新任务结束或停止后释放 Worker。
- 运行文件固定来源/摘要，gzip 随包及公共运行缓存，保留第三方许可。
- 真实本地网站的标准库、中文/emoji、20次运行、错误、内存、停止/恢复和
  128KiB源码+200,000字符输入已验证。公网/离线扩展是独立的待验收项目。
- rc.3及此前所有固定源码、包、部署和最初回退快照保留。

不更新 stable tag、镜像 latest 或商店。真实 AI、两真实账号、用户旧安装
升级和根许可证选择等原始门槛继续保留。详细状态见 unified-acceptance.json
和 unified-delivery-log.md；不会以代码构建通过替代完成18项计划。
