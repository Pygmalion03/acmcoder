# ACMCoder v4.0.0-rc.5

这是统一产品候选版，不是稳定发布或商店上架声明。网站、插件与本地构建统一使用4.0.0-rc.5；插件数字版本4.0.0.5。此前rc.1–rc.4源码归档、安装包、固定网站部署和最初回退检查点保留。

本候选包含rc.4的浏览器C++17适配、Python练习和长期数据功能，补入共同图标、可重建的440×280品牌宣传图、数据与隐私页面及设置入口。C++公网执行和真实已安装插件的断网验收仍需分别完成，不能用压缩资源分发成功代替运行成功。

网站完整构建使用 `npm run build:pages`：公开运行资源保留为静态文件，模块入口复用现有API并由固定esbuild0.28.1打包为 `_worker.js`，静态请求转给Pages ASSETS绑定。`_routes.json`只对 `/api/*` 调用Worker；本地检查已知源码提交、统一首页、静态单文件25MiB上限、免费文件数、Worker模块语法/压缩体积和C++资源摘要；重定向后的无后缀沙箱地址同样保留CSP。产物拒绝未解决或Node专用模块依赖；部署走已有GitHub连接，不将编译器内嵌在Worker中，不读取或改变仪表盘的OAuth秘密及D1绑定。

候选Actions产物包含源码、扩展ZIP、校验和、品牌素材与Pages构建清单。实际部署ID、ZIP摘要和镜像标识写入交付日志和发行清单后才算关联完成；清单的 `not-deployed` 表示本地准备状态。不会自动提升稳定渠道或覆盖旧安装数据。

真实AI三端调用、原创导题、两个真实账号、用户原有稳定安装升级、根许可证与商店身份仍待完成，原18项验收门槛保持。公开隐私地址及真实插件截图以实际验收记录为准。
