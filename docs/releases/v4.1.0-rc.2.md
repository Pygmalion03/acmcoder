# ACMCoder v4.1.0-rc.2

修复 rc.1 在新版本下载完成后，Java 隔离启动页尚未实际加载，导致首次断网编译仍可能超时的问题。离线准备现在会真实加载带 nonce 的隔离页，收到指定帧、null origin 和相符 nonce 的 ready 握手后，才显示三语言资源已就绪。仅缓存运行文件字节不能代替这一检查。

rc.1 的固定源码 b8318b2、插件包、对应 Java 源码包和候选 Docker 镜像继续保留；v4.0.0 稳定 latest 不更改。其 403 项固定源码测试、GitHub 候选构建和两种 Docker 镜像发布已通过。日常 Chrome 插件同 ID 升级后，7 条匿名记录和 18 条账号记录的内容与引用保留；真实账号/AI/Java 编译及 JavaScript 隔离通过。

其余 Java 8、分配预算、时限、源代码和许可证边界沿用 rc.1 说明。公网网站部署仍需恢复 Cloudflare 授权，并对真实账号离线重连单独验收；本地原型通过不代表该公网路径已完成。
