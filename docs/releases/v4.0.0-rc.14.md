# ACMCoder v4.0.0-rc.14 — 待实装验收

本候选修复公开ZIP新目录安装后的账号连接问题。rc.13使用目录决定的插件ID，未登记ID被网站拒绝，不能完成跨设备连接。

已登记ID保留PKCE授权回调。新ZIP安装的未登记ID使用网站既有设备确认流程：用户选择GitHub账号并明确确认，插件后台才兑换独立同步授权。回调名单、manifest权限、运行资源和学习存储结构不变。设备确认页关闭且未批准时取消；批准后即使关闭确认页，插件仍可完成兑换。

待确认请求仅在可信session存储中保留十分钟，设备秘密不传给网页、界面消息或执行沙箱。每次轮询为短后台请求，后台重启后可以继续；页面刷新后再次点击连接可接续原请求。取消与兑换并发时不恢复本机连接，并撤销刚签发的授权。

已补相关实现回归，包含未确认无授权、单次兑换、错误状态、可信消息来源、后台重启、关闭/过期、保持连接与取消并发。测试通过不能代替真实GitHub登录及浏览器实装。

本版提供候选源码tar.gz、插件ZIP、SHA256SUMS和关联清单；实际网站部署/镜像digest以[rc.14 Release](https://github.com/Pygmalion03/acmcoder/releases/tag/v4.0.0-rc.14)为准。两镜像tag分别为`ghcr.io/pygmalion03/acmcoder-app:v4.0.0-rc.14`与`ghcr.io/pygmalion03/acmcoder-runner:v4.0.0-rc.14`；确认镜像已发布后，在本版源码目录执行 `docker compose -f docker-compose.prebuilt.yml -f docker-compose.candidate.yml up -d`。旧[rc.13](https://github.com/Pygmalion03/acmcoder/releases/tag/v4.0.0-rc.13)包与镜像保留，本版候选发布不等于最终稳定验收通过。
