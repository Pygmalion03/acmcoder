# ACMCoder v4.0.0-rc.12

设置页的自带API卡片现在与其他设置使用同一宽度；桌面上的地址/模型、密钥/口令并排，侧栏使用单列。题库标题、找题区、筛选与列表对齐，找题输入和按钮并排，减少无用途的留白。

AI问答不再一次性渲染全部历史。对话区固定高度、独立滚动，默认展示最近20条；更早、更新和回到最新可翻看完整会话，每次最多20条。输入区不属于历史滚动区，翻页不改变问题草稿。存储、导出备份、同步及模型上下文规则保持原有行为，历史不按显示数量截断。

隔离本地预览的203条历史已通过实际Chrome翻页、最早边界及返回最新检查；保存和导出仍为203条，刷新后的问题草稿保留。固定源码f3c7078的375/375测试、三端/Pages构建与候选包检查通过；网站部署1c5fb1e3、本地及同ID插件已更新。三端产物与部署结果在交付日志中记录。旧rc.11产物与运行目录保留。
