# ACMCoder v4.0.0-rc.2 统一候选版

本候选版在统一界面基础上补齐旧自测次数迁移、旧AI配置的独立凭据保管，以及每天100次新增云端自测记录的限制。源码、网站、插件和本地界面由同一commit构建；稳定版仍为3.0.4。rc.1的固定源码包、镜像和网站部署保留以便核对与回退。

## 本批行为

- 旧本地自测次数进入统一记录、完整备份和界面；不补造不存在的程序或运行历史，重启不重复累计。
- 旧AI接口首次读取配置时，将明文Key迁到独立0600凭据文件。失败保留原配置；先提交凭据再清理普通设置。统一页继续采用用户自行配置的vault，不返回旧服务器Key。
- 新增云端自测记录按服务器UTC日期每日100次。超额结果保留在本机和持久待同步队列，次日继续；草稿和其他记录仍可同步。重试、失败事务与旧服务器历史迁移不重复扣除额度，删除历史不返还当天额度。
- 新迁移文件0005只增加计数表和事务约束，不清理历史或修改已应用的迁移。回退静态资源不反向删除新数据。
