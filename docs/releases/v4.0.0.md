# ACMCoder v4.0.0

首次统一正式版。网站、浏览器插件和本地/Docker共用题库、今日安排、ACM练习、重写、长期历史、备份、GitHub同步和自带API问答。

网站与插件运行Python、C++17；本地/Docker还支持Java。插件包含离线运行资源，可在LeetCode侧栏直接练习，无需部署本地服务。商店尚未上架，使用Release的生成ZIP安装。源码目录 `extension/` 不能代替生成包。

本版修复删除题目后子记录的重复墓碑被显示成空冲突：双方都已删除时自动确认；另一端的离线编辑仍保留真实冲突，可另存为新题。旧候选已存下的空冲突在下一次同步时清理。题库操作按钮保持完整文字，小侧栏允许按钮组换行；设置页复选框不再撑满输入区域。

AI对话在固定高度区域内每页显示20条；完整记录继续保存、备份和同步。历史没有30天或100条自动删除规则。API密钥不进入学习备份或云端同步。

## 安装与升级

从[正式Release](https://github.com/Pygmalion03/acmcoder/releases/tag/v4.0.0)下载源码、插件ZIP、校验和及发行清单。网站入口为 https://acmcoder-unified-preview.pages.dev/ 。固定源码、部署和镜像摘要以随包 `release-manifest.json` 为准。

Docker在源码包目录使用：

```sh
docker compose -f docker-compose.prebuilt.yml -f docker-compose.release.yml pull
docker compose -f docker-compose.prebuilt.yml -f docker-compose.release.yml up -d
```

保持既有数据目录与挂载；升级前导出完整学习备份。插件更新原安装目录并重新加载，保持安装ID。rc.14包、固定部署和版本镜像继续保留，回退使用升级前独立数据副本，保留升级后的新记录。详见[升级说明](../upgrade.md)。
