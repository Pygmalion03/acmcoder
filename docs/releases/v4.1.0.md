# ACMCoder v4.1.0

本版将已验收的 v4.1.0-rc.3 发布为正式版，功能代码保持相同，统一更新版本标识、安装指引和发行关联。v4.0.0 及三个候选版本的源码、制品和数据备份继续保留。

- 网站完整离线准备后，断网刷新、关闭重开均可练习 Python、C++17 和 Java 8；草稿与输入保留，联网后恢复账号同步。
- 浏览器 Java 8 编译并运行完整 ACM 程序；日常 Chrome 插件真实 GitHub、AI 和与网站同步已通过。
- 修复 Cloudflare Pages 跳转响应缓存导致首页打不开的问题，并在当前版本完整下载后才报告离线就绪。

首次网站离线准备约 81 MB，浏览器清理缓存后需重新联网准备。外部 AI、导题和同步需要联网。浏览器 Java 为 Java 8，编译时保持页面可见；本地原生 Java 版本不同。运行器累计分配预算不代表浏览器总内存上限。自测通过不代表原平台隐藏测试 AC。

[增量功能验收](evidence/v4.1-incremental-2026-10-02.json)保留实际候选版本与固定源码，不改名冒充正式版实测。正式发行的源码、网站部署、镜像与下载包关联以随包 release-manifest.json 为准。源码 MIT，第三方运行资源保留各自许可证，Java对应源码随包发布。Chrome商店上架仍按用户决定留待以后；手动加载插件无需付费。
