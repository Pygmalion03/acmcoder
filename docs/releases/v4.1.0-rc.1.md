# ACMCoder v4.1.0-rc.1

本候选补齐网站离线重开、浏览器 Java 8，并继续核对日常 Chrome 插件的真实账号与 AI。v4.0.0 的固定源码、网站部署、ZIP、镜像及数据备份继续保留。

网站离线资源显示就绪后，可断网重开，已有草稿和历史保存在原本机/账号副本中。Python、C++ 与 Java 的公共运行资源固定校验；离线缓存不保存 API、账号令牌、密钥或学习内容。同步、外部题目抓取和 AI 仍需联网。

Java 接受完整 `public class Main` 程序，在浏览器中编译并处理 stdin，支持 Java 8 语法与所带标准库。执行累计分配预算 64 MiB，编译预算 256 MiB，执行最多 5 秒，编译/启动最多 30 秒，输出最多 32,768 字符；累计预算不是 GC 堆大小。后台标签页可能被浏览器节流，编译请保持工作区可见。首次在线准备全部离线资源约需 80 MB，实际大小以产物清单为准。

本地开发候选的真实 Chrome 结果：Python/C++ 断网重载、停止预览服务器后新标签页重开并执行通过；Java 完整程序、集合与中文输出、断网重载、超限数组停止、死循环超时和恢复通过。公网部署、更新后的日常插件、账号离线重连及版本产物关联仍须单独验收，不把本地结果当作公网交付。

Java 许可文本随运行资源保留，对应 OpenJDK 源码、Ubuntu 补丁、Doppio、BrowserFS 和 JCL 构建源码另打包提供，详见 `third_party/java/README.md`。候选发布不更改 v4 稳定 latest。
