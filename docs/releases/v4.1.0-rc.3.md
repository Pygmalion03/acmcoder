# ACMCoder v4.1.0-rc.3

公网验收发现 Cloudflare Pages 会将 `.html` 跳转到无后缀地址。缓存中保留了已跳转的响应，导致首页导航被浏览器拒绝，正常联网重开也会出现 ERR_FAILED。现将通过 SHA256 验证的静态内容保存为直接响应，保留安全策略并移除传输编码和原传输长度。新增导航重定向回归检查。

Java 首次离线启动握手沿用 rc.2。rc.1、rc.2 和 v4.0.0 的源码与制品继续保留，稳定 latest 不更改。公网三语言离线重开与真实账号恢复现已通过，下文记录固定源码与证据。

最终固定源码 `587406427363d97df202f242c80b93bc0e53404d`：405/405、Docker 烟测及双架构 app/runner 候选镜像通过。主站生产部署 [de90fbee](https://de90fbee.acmcoder-unified-preview.pages.dev/)；同一源码的独立预览部署 [58475243](https://58475243.acmcoder-unified-preview.pages.dev/)用于首次离线重开，三语言输出 42，主站真实账号断网重开 Java 输出 8、重连后网站与日常插件 24 条记录正文相同。日常插件真实 GitHub / AI / Java 通过，本地 13 条原记录内容与引用保留。完整增量回执见 [验收证据](evidence/v4.1-incremental-2026-10-02.json)。
