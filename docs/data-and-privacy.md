# 数据与隐私

ACMCoder采用先保存在当前设备、可选同步的方式。不自动按记录时间或最近N条清理题目、代码、输入、重写历史、运行记录和对话。

| 内容 | 网站 | 插件 | 本地 / Docker |
| --- | --- | --- | --- |
| 题目、代码、stdin、历史、对话 | 当前浏览器IndexedDB，账号/匿名空间分开 | 插件IndexedDB，账号/匿名空间分开 | data/unified中的文件事务存储；旧数据保留在原目录 |
| 云端副本 | 登录并同步后在Cloudflare D1 | 主动授权设备并同步后在D1 | 主动授权设备并同步后在D1 |
| API Key | 默认页面内存；可选口令加密后在本机保存 | 默认页面内存；可选口令加密后在本机保存 | 统一页默认页面内存；可选口令加密后在浏览器保存；旧接口配置读取时迁入独立0600凭据文件 |
| 设备授权 | 网站会话 | access在可信session；自选保持连接才保存轮换refresh | 独立credentials目录的0600文件，不放入学习记录 |

浏览器保存API Key采用Web Crypto PBKDF2-SHA256（600000次，随机salt）与AES-GCM（每次随机IV）。口令和解密后的密钥不写盘；刷新后需解锁。不要把Key粘贴进代码、题面或聊天正文；普通正文属于用户学习记录，不承诺能识别其中所有用户主动写入的秘密。

网站AI通过已登录的短时同源转发，只允许预设兼容HTTPS地址，不跟随重定向；Key随单次请求在内存中传给所选提供商，不写入D1、普通设置、学习备份或同步。网站当前转发每天20次并限制请求频率；插件与本地直接请求用户所选服务。兼容地址注册并不代表真实模型已经验收。插件只为用户选定的origin申请可选访问权限，本地HTTP仅可显式使用本机回环地址。

AI提供商收到本次问题及受限的同题对话上下文。用户勾选“附带当前题面、代码和输入”才附带这些内容；不自动发送其他题目。连接测试也会发出一次小请求。模型费用由用户的提供商按其规则收取，ACMCoder不代为购买额度，也不缺Key时切换到共享付费模型。

GitHub登录用于识别账号；本站使用公开资料权限，不要求私有仓库权限。插件和本地独立设备授权可在网站设置撤销；撤销停止云端接续，保留设备上的练习。

归档可恢复，仍计云端容量。彻底删除题目会删除关联学习内容，并保留不含正文的最小删除标记防止旧设备复活。云端容量目前默认200题、每账号8MiB学习记录预算，实际配置可在设置查看；不足时暂停新写入并保留已有记录、设备练习和备份，不自动升级收费资源。统一接口每账号每日新增云端自测记录100次，按服务器UTC日期计算，UTC零点恢复额度；重试不重复计数，删除已存记录不返还当天额度。达到日上限后继续本机运行、保存和导出，新增运行记录留在持久待同步队列，次日接续；草稿及其他内容仍可同步。旧服务器记录的内部迁移不占新的日额度，完整历史不会因此被截断。

删除云端账号数据需要明确输入DELETE；删除云端题目、代码、历史、对话、旧表残留和全部会话/设备授权。浏览器或离线设备上的本机副本不会因此被远程抹除，需用户在对应设备自行清理。已有独立备份也不会自动被擦除。

同浏览器插件/网页接续只传选中题目，需用户点击并确认，不要求登录、不暗中上传。传送标识5分钟有效、单次消费、绑定目标标签页；URL不带学习正文。

清除网站数据、卸载插件或删除本地数据目录可能移除未同步、未备份内容。完整导出是独立恢复手段，云端同步不能代替个人备份。4.0.0 网站需要联网加载；4.1 候选版在「网站离线」显示资源已就绪后，可以断网重开和继续 Python、C++、Java 8 练习。首次准备需要联网，浏览器清理或回收缓存后需重新准备。离线账号只选择已有本机副本，不产生服务端登录权限；API、Cookie、Key 和学习记录不进入离线页面资源缓存。同步、外部导题和 AI 请求需要联网。完整插件包或已安装的本地工具链/镜像仍可独立长期离线使用。

产品设置中的“阅读数据与隐私说明”打开随包 `shared/privacy.html`，无需登录或外部脚本。[公开隐私说明](https://acmcoder-unified-preview.pages.dev/shared/privacy)已在 rc.5 验证匿名200响应、无脚本策略与真实浏览器排版。功能或隐私请求可通过[项目 Issues](https://github.com/Pygmalion03/acmcoder/issues)提出，公开提交时不要附上Key、授权值或个人学习备份。
