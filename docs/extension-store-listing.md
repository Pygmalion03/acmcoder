## 展示文案

名称：**ACMCoder**

简短说明：**在浏览器侧栏练习 ACM 格式，保存代码与重写历史，支持离线 Python/C++ 和可选跨设备同步。**

完整中文说明：

ACMCoder 是面向桌面浏览器的 ACM 格式练习空间。打开 LeetCode 题目后，一键读取题面和原始样例，在侧栏编写完整程序，自行整理标准输入并运行 Python 或 C++17 自测。基础练习无需网站登录或启动本地服务。

代码、输入、期望输出和历史保存在当前设备。完成一题后可以重新手撕，对照原来的记录；题库与今日安排帮助你继续练习。题目归档后可恢复，完整备份可导出并合并恢复。扩展安装包包含 Python/C++ 运行资源，断网仍能练习已保存的题。

你可以主动连接 GitHub 账号，把练习同步到自己的其他设备；也可以在同一浏览器的网站和插件之间接续选中的题目。匿名空间不会因为登录而自动上传。同步是可选功能，网站标签页无需一直打开。

插件提供自带兼容 API 的 AI 设置：用户选择服务、模型并自行填入 Key，为该服务授予可选访问权限后才发送请求。Key 默认只在当前应用会话内存中；可选本机口令加密保存。普通学习备份和同步不包含 Key。模型回答不会自动替换编辑器代码。网站、实装插件及本地的真实兼容提供商问答、取消和错误恢复已通过，原代码/输入保留；详见三端AI收据。不承诺任意服务或协议兼容。

当前公开网站与可下载ZIP对应rc.13/e844d9e，运行资源沿用已验收实现。最近实装插件仍为rc.12，升级到公开下载的rc.13后须补新安装/回退和最终截图收据，不能仅从文件版本推断浏览器已激活。网站和插件提供Python/C++17，本地提供Python/C++/Java。自测通过不等于LeetCode原平台隐藏测试AC。

## 单一用途与权限理由

单一用途：读取用户选择的算法题，并在浏览器侧栏进行 ACM 输入输出练习，保存及可选接续同一份学习记录。

| manifest 项目 | 具体用途 / 源码依据 |
| --- | --- |
| `activeTab` | 用户点击后识别当前练习页面，读取该题；`capture.js` |
| `scripting` | 安装/更新后已打开的 LeetCode 页面没有接收端时，注入包内固定 content-script；不注入任意远端 JS；`capture.js` |
| `sidePanel` | 打开 ACM 练习侧栏；`background.js` |
| `storage` | 保存偏好及受信任上下文中的设备授权；学习记录另在 IndexedDB；`auth.js`、`handoff.js` |
| `identity` | 用户主动连接账号时的设备授权回调；不申请私有仓库权限；`auth.js` |
| `tabs` | 创建/定位同浏览器接续的准确目标标签页，检查切题及本扩展工作区 URL；不保存或上传完整标签页列表；`handoff.js`、`capture.js` |
| `https://leetcode.cn/*` / `https://leetcode.com/*` | 从用户选中的题目页或明确题目链接读取题面/样例，必要时使用同站 GraphQL；`content-script.js`、`background.js` |
| 两个 ACMCoder 网站 origin | 用户主动的同浏览器接续与账号设备同步；固定来源验证；`website-bridge.js`、`handoff.js`、`auth.js` |
| `http://127.0.0.1:43117/*` | 原版兼容入口在用户主动选择后连接本地 ACMCoder 服务；不会使基础 Python 练习依赖本地服务 |
| 可选 `https://*/*` | 声明自定义模型提供商可能使用的 HTTPS origin。实际由 `chrome.permissions.request` 仅申请用户在设置中指定的单个服务 origin；不是安装时全网授权；`ai.js` |

## 数据使用与隐私

提交表单应根据最终源码逐项核对，不能笼统勾选“不处理用户数据”。本插件处理题面/来源 URL、用户编写的代码与输入、练习对话、GitHub 公开账号标识以及独立设备授权/用户 Key。账号同步会把用户明确同步的学习记录传给 ACMCoder 云端；模型请求只发给用户所选提供商。当前页面 URL 只用于题目来源验证，代码没有 `chrome.history` API，也不把完整标签页列表当学习记录上传。

建议表单核对：账号标识对应个人识别信息；设备凭据/Key 对应认证信息；题面和用户代码对应网站内容；来源页面 URL 是否需在商店的浏览记录分类申报按最终表单口径确认；对话按其文字内容及用途准确申报。不得因为部分内容只存本机就隐藏处理行为。项目不将学习数据出售、用于广告或信用判断；发布者最终认证须自行确认这些声明。

完整政策来源：[数据与隐私](data-and-privacy.md)。网站/插件/本地提供共同的 `shared/privacy.html` 页面及设置入口。[公开隐私 URL](https://acmcoder-unified-preview.pages.dev/shared/privacy)在rc.6 HTTP复查匿名200与无脚本策略通过，实际排版沿用rc.5浏览器验收；商店发布前需再次核对最终版本。仓库 Issues 与政策源文件的匿名 HTTP 访问已确认返回200；不虚构客服邮箱。

## 执行代码声明

Python 与 C++ 运行器的 JS、WASM、标准库都在候选 ZIP 包内；不从 CDN 拉取可执行依赖。模型 API 和题目抓取返回内容数据，普通回答不被当作扩展脚本执行。用户程序仅在不具有扩展 API/应用存储/网络能力的隔离帧 Worker 内执行。内容脚本内的共享题面规则构建为经典IIFE，没有新增权限或远端代码。审查应说明这种用户编程场景，不能只提交“没有任何执行代码”的笼统描述。

Chrome 官方要求包内提供运行代码，并说明隔离帧场景：[远程托管代码说明](https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code)。Microsoft 要求 MV3 不加载远程托管代码，权限/隐私声明与实际行为一致：[Edge 提交说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension)。这些说明不保证本插件将获商店通过。

## 审核员可复现流程

无需给审核员共享个人 Key 或 GitHub 账号：

1. 安装最终 ZIP/商店测试包，打开一个公开 LeetCode cn/com 题目页，点击图标进入侧栏，再读取当前题目。
2. 新建或编辑 ACM 输入，运行简单 Python，关闭侧栏后重新打开，核对代码/输入仍在。
3. 点击重新手撕，结束后查看原快照；去题库/今日页，确认可见且可回到练习。
4. 导出学习备份，使用自建测试题核对包含草稿/历史，Key 不在普通导出内。
5. 在安装完整候选包后断网，运行已保存的 Python/C++ 简单题；账号/AI 网络功能清楚显示连接限制。
6. 若验证同步，由审核员自行选择真实账号授权；正式商店扩展 ID 必须已登记网站回调。AI 使用审核员自行提供的兼容服务，用户界面不要求交出个人密钥。
