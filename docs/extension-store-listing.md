## 商店展示文案

名称：**ACMCoder**

简短说明：**在浏览器侧栏练习 ACM 格式，保存代码与重写历史，支持离线 Python/C++ 和可选跨设备同步。**

完整中文说明（提交时仅复制以下产品描述，不复制验收记录）：

ACMCoder 是面向桌面浏览器的 ACM 格式练习空间。打开 LeetCode 题目后，一键读取题面和原始样例，在侧栏编写完整程序，自行整理标准输入并运行 Python 或 C++17 自测。基础练习无需网站登录或启动本地服务。

代码、输入、期望输出和历史保存在当前设备。完成一题后可以重新手撕，对照原来的记录；题库与今日安排帮助你继续练习。题目归档后可恢复，完整备份可导出并合并恢复。插件安装包包含 Python/C++ 运行资源，断网仍能练习已保存的题。

你可以主动连接 GitHub 账号，把练习同步到自己的其他设备；也可以在同一浏览器的网站和插件之间接续选中的题目。匿名空间不会因为登录而自动上传。同步是可选功能，网站标签页无需一直打开。

你也可以配置自己的兼容模型 API，与 AI 自由讨论题目。只有为你选择的模型服务授予访问权限后，插件才会发送请求。API Key 默认只保留在当前应用会话，也可用本机口令加密记住；普通备份和同步不包含 Key。模型回答不会自动替换编辑器代码，模型费用由所选提供商收取。

网站与插件支持 Python/C++17，本地版和 Docker 还支持 Java。这里只进行用户配置输入和期望输出的自测；样例通过不代表 LeetCode 原平台隐藏测试 AC。插件不绕过原题网站登录或付费限制。

项目网站：https://acmcoder-unified-preview.pages.dev/

支持入口：https://github.com/Pygmalion03/acmcoder/issues

公开隐私政策：https://acmcoder-unified-preview.pages.dev/shared/privacy.html

产品免费；不包含共享付费 AI 额度。分类建议选择教育/学习类，以后台实际可选项为准。

## 单一用途与权限理由

单一用途：读取用户选择的算法题，并在浏览器侧栏进行 ACM 输入输出练习，保存及可选接续同一份学习记录。

| manifest 项目 | 具体用途 / 源码依据 |
| --- | --- |
| `activeTab` | 用户点击后识别当前练习页面，读取该题；`capture.js` |
| `scripting` | 安装/更新后已打开的 LeetCode 页面没有接收端时，注入包内固定 content-script；不注入任意远端 JS；`capture.js` |
| `sidePanel` | 打开 ACM 练习侧栏；`background.js` |
| `storage` | 保存偏好及受信任上下文中的设备授权；学习记录另在 IndexedDB；`auth.js`、`handoff.js` |
| `identity` | 用户主动连接账号时的设备授权回调；不申请私有仓库权限；`auth.js` |
| `tabs` | 创建/定位同浏览器接续的准确目标标签页，检查切题及本扩展工作区 URL；不保存或上传完整标签页列表；`handoff.js`、`capture.js` |
| `https://leetcode.cn/*` / `https://leetcode.com/*` | 从用户选中的题目页或明确题目链接读取题面/样例，必要时使用同站 GraphQL；`content-script.js`、`background.js` |
| 两个 ACMCoder 网站 origin | 用户主动的同浏览器接续与账号设备同步；固定来源验证；`website-bridge.js`、`handoff.js`、`auth.js` |
| `http://127.0.0.1:43117/*` | 原版兼容入口在用户主动选择后连接本地 ACMCoder 服务；不会使基础 Python 练习依赖本地服务 |
| 可选 `https://*/*` | 声明自定义模型提供商可能使用的 HTTPS origin。实际由 `chrome.permissions.request` 仅申请用户在设置中指定的单个服务 origin；不是安装时全网授权；`ai.js` |

## 隐私表单准备

不得勾选笼统的“不处理用户数据”。以下根据最终安装包准备；实际后台分类与声明须在登录后逐项匹配。

| 处理内容 | 用途与去向 | 表单核对分类 |
| --- | --- | --- |
| GitHub公开账号标识 | 用户主动授权后识别自己的云端同步空间 | 个人识别信息 |
| 设备授权、用户API Key | 同步认证及用户自选模型认证；不进入普通备份或同步 | 认证信息 |
| 题面、代码、stdin、期望输出、历史与对话 | 当前设备保存；用户主动同步至ACMCoder，或主动提问至所选模型 | 网站内容；对话具体分类按后台口径核对 |
| 当前题目URL | 捕获、来源验证和选中题目接续；不收集完整浏览历史 | 浏览活动/网站内容按后台口径准确申报 |

代码没有chrome.history API；不会把完整标签页列表作为学习记录上传。学习数据不用于出售、广告、信用判断或与单一用途无关的用途。没有分析统计SDK。认证值、个人学习备份和用户模型地址不随审核材料上传。

模型请求只发送本次问题及有限的同题上下文。用户勾选附带题面/代码/输入后才发送这些内容，不自动发送其他题目。匿名数据仅在设备保存；连接账号不自动上传匿名空间，合并需要用户主动操作。撤销设备停止同步并保留本机内容。归档可恢复；彻底删除传播删除标记防止旧设备复活。完整保留规则见[数据与隐私](data-and-privacy.md)。

正式提交时应按后台展示的原文核对数据使用认证项；不存在的字段不能伪造已填写。不得把本文件准备好的说明称为后台已通过验证。

## 包内执行与审核说明

正式ZIP中的Python/C++运行器JS、WASM与标准库均随包安装，不从CDN下载执行依赖。题目/API请求用于内容数据，不自动把回答当扩展脚本执行。用户在代码编辑器主动输入的程序只在包内声明的隔离帧Worker执行，不获得扩展API、应用存储、凭据或网络能力；CSP使用connect-src 'none'。C++编译器为包内固定资源，生成的用户程序WASM也在该隔离环境运行。

## 审核员流程

基础练习无需个人GitHub账号或API Key。请安装上传的完整ZIP，勿直接加载源码extension/目录。

1. 打开公开题目 https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/description/ ，点击ACMCoder图标进入侧栏，再点击读取当前LeetCode题目。题面与原始样例保留，标准输入由用户自行整理。
2. Python代码输入print(sum(map(int,input().split())))；stdin填17 25，期望输出填42，点击运行自测应显示样例通过。
3. 关闭并重新打开侧栏，代码和输入仍在。点击重新手撕，完成后打开历史对照，原快照仍在；题库和今日可以返回练习。
4. 设置中导出备份，完整备份包含题目/草稿/历史/对话，不包含认证配置。用审核员自己的测试数据验证合并恢复，不使用开发者私人备份。
5. 完整安装后断开网络，可运行已保存题目的Python或C++17；账号同步与AI则需要网络。C++可使用#include <iostream>及int main(){int a,b;std::cin>>a>>b;std::cout<<a+b<<'\n';}测试17 25得到42。
6. 同步是可选步骤，审核员可用自己的GitHub账号明确批准设备，并在网站设备管理中撤销。AI也为可选步骤，只支持审核员自己提供的兼容服务与Key；基础体验不需要任何共享测试凭据。
