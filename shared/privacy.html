你的学习记录

题目、代码、标准输入、期望输出、重写历史、运行记录、今日安排和对话保存在当前设备。网站及插件使用各自的 IndexedDB，匿名空间与账号空间分开；本地/Docker 版使用本地数据目录。我们不自动按时间或最近条数删除这些记录。

连接 GitHub 后可同步你选择的学习记录，云端副本位于 Cloudflare D1。登录不会自动上传匿名内容；合并匿名练习需要你主动操作。同步冲突保留双方，由你选择如何处理。

云端默认容量为 200 题、每账号 8 MiB 学习记录，实际配置在设置中查看。每日新增云端自测记录最多 100 次，按 UTC 日期恢复；重复请求不重复计数，删除不返还当日额度。达到容量或日额度时暂停相应新增写入，设备练习、已有记录与备份保留；待同步的运行记录会在额度恢复后接续。归档仍计题目容量。这些不是设备保存的题数或历史保留上限。

API Key 与 AI 请求

你选择提供商、模型并自行配置 Key。Key 默认只在当前页面会话内存中；可选用本机口令加密保存。加密使用 Web Crypto PBKDF2-SHA256（600,000 次、随机 salt）及 AES-GCM（随机 IV）；口令和解密后的 Key 不写盘，刷新后需重新解锁。普通学习备份和同步不包含 Key。

统一本地页面遵循同样规则。原版本地接口的旧配置会迁入独立的本机凭据文件，权限为 0600，普通配置文件不保存 Key；该文件不属于学习记录目录。

网站 AI 使用已登录的短时同源转发，将本次 Key 在内存中传给你选择的兼容 HTTPS 服务，不写入数据库、普通设置、学习备份或同步。当前网站转发每天 20 次，并限制频率。插件和本地版直接请求所选服务；插件仅在你确认后为指定 origin 申请可选访问权限。本地 HTTP 服务仅可显式配置回环地址。

提供商收到你的本次问题及受限的同题对话上下文；只有勾选“附带当前题面、代码和输入”才附带这些内容，不自动发送其他题目。连接测试也会发出一次小请求。提供商的数据处理及费用受其自身规则约束，ACMCoder 不代购额度，也不在缺少 Key 时切换到共享付费模型。兼容接口不代表所有模型已经验收。

不要将 Key 写入代码、题面或聊天正文：这些正文属于普通学习记录，我们不能保证识别其中所有你主动写入的秘密。

账号与浏览器权限

GitHub 登录用于识别账号，只使用公开资料权限，不要求私有仓库权限。网站会话、插件设备授权和本地设备授权各自管理。插件的临时授权只在可信会话中；选择保持连接时才保存轮换授权。本地设备授权在独立凭据目录的 0600 文件中。网站设置可撤销设备，停止云端接续并保留设备练习。

插件只读取你选择的题目页，使用 LeetCode 来源 URL 验证题面与样例，不读取浏览器历史或上传完整标签页列表。页面和插件之间的接续只传选中的题目，需要你点击并确认；无需账号、不暗中上传。一次性传送标识绑定目标标签页，5 分钟有效，URL 不携带学习正文。

网站和插件的用户程序在独立浏览器隔离运行器内执行，不具有扩展 API 或应用存储访问能力；插件运行器不允许联网。网站 Python 首次加载需下载固定运行资源，因此离线边界与完整插件包不同。插件安装包包含运行所需代码与资源；题面和模型响应作为内容数据处理，普通回答不会被当作扩展脚本执行或自动替换你的代码。

归档、删除与备份

归档可恢复。彻底删除题目会删除关联学习内容，并保留不含正文的最小删除标记，防止旧设备恢复原 ID 的数据。

删除云端账号数据需要明确输入 DELETE，会清除云端题目、代码、历史、对话、旧表残留以及所有会话与设备授权。离线设备或浏览器上的本机副本不会被远程抹除，需要在对应设备自行清理；已有独立备份也不会自动擦除。

清除网站数据、卸载插件或删除本地数据目录可能移除未同步、未备份的内容。完整导出是独立恢复手段，云端同步不能替代个人备份。网站不保证首次加载、资源下载或断网重新打开可用；长期离线练习请先安装完整插件包或本地工具链/镜像。

数据用途与联系

我们处理上述内容用于练习、保存、可选接续、账号识别和你主动发起的 AI 请求，不出售学习数据，不将其用于广告或信用判断。

功能问题或隐私相关请求可通过 项目 Issues 提出；公开提交时不要包含 Key、授权值、私人代码或个人备份。政策源文件和更新记录可在 源码仓库 查看。
